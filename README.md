## Overview
This is a group of ROS2 packages responsible for task planning features of [FBOT@Work](https://fbotwork.vercel.app/) industrial robot (MICKY) in RoboCup@Work league.

## Pre Requisites

- ROS2 Humble
- Python 3.10+
- Ubuntu 22.04
